# Superstore Sales Analytics & Profit Prediction

## Project Overview
This project was developed for the AICTE | IBM SkillsBuild Data Analytics with AI Internship. It analyzes a retail superstore's dataset to extract actionable business insights using Python and predicts future profitability using a Random Forest machine learning model.

## Dataset
The dataset used is the [Sample Superstore Dataset from Kaggle](https://www.kaggle.com/bravehart101/sample-supermarket-dataset).

## Technologies Used
* Python 3.x
* Pandas (Data manipulation)
* Matplotlib & Seaborn (Data visualization)
* Scikit-Learn (Machine Learning)
* Jupyter Notebook

## Setup & Run Instructions
1. Clone this repository to your local environment.
2. Download the Kaggle dataset and ensure `SampleSuperstore.csv` is in the same directory as the notebook.
3. Install the required dependencies using the terminal: `pip install -r requirements.txt`
4. Open `VedantKaushal_SuperstoreSales.ipynb` in Jupyter Notebook or Google Colab.
5. Run all cells sequentially to view the exploratory data analysis and train the predictive model.
